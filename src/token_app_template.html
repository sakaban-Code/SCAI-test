關鍵數字

數字取自三個工具的本機原始 usage 欄位，非估算。 刻意不提供單一「總 token」——四項直接相加會被快取重讀主導， 技術上為真但誤導一個數量級。

三種口徑 「這數字怎麼來的？可信嗎？」

歸屬決定逐檔記錄在 並進版控， 使「哪些 token 算 SCAI」這個判斷本身可被稽核。下界與上界一併給出，不挑對自己有利的講。

口徑則新輸入快取寫快取讀 output輸入計價當量處理總量命中率

「處理總量」＝實際被處理的 token（含重讀快取），衡量工作規模； 「輸入計價當量」＝依快取倍率折算，反映成本結構。報告請引用後者。
